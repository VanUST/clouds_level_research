# The paper

`main.pdf` — a self-contained 15-page account of the whole programme, written for a reader
with no prior context. 15 sections, 13 tables, 6 figures.

    pdflatex main.tex && pdflatex main.tex      # two passes, for the cross-references

`main.tex` is the single source. Figures are generated as PNG elsewhere in the repository and
converted to PDF for inclusion; `figures/*.pdf` are build products and are regenerated by:

    python3 -c "from PIL import Image; import glob; \
      [Image.open(f).convert('RGB').save(f[:-4]+'.pdf','PDF',resolution=300.) \
       for f in glob.glob('figures/*.png')]"

## What it covers

| section | content |
|---|---|
| 1–3 | the rig, the reference, the session; fisheye geometry, the three measured calibration terms, exact triangulation |
| 4 | the pre-registered matcher comparison, including the unresolved config/analysis inconsistency |
| 5 | the synthetic control — the renderer's gate, and the selection-rule defect it exposed |
| 6–7 | the real-data anomaly, and all twelve pre-registered refutations |
| 8–11 | the static field, the cross-validated correction search, the shape mechanism, the detection floor |
| 12 | supporting measurements (temporal alignment, the static map, texture scale) |
| 13 | the six harness defects and the provenance assertions |
| 14–15 | discussion, threats to validity, conclusion |

Every number is traceable to a machine-readable artefact; the mapping is in the
Reproducibility section of the paper.
